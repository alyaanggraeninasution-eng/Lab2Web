soal:
1. Apa fungsi <table>, <tr>, <th>, dan <td>?
2. Apa perbedaan <th> dan <td>?
3. Apa fungsi colspan pada tabel?
4. Apa fungsi <form> dalam HTML?
5. Apa perbedaan radio button dan checkbox?
6. Mengapa <label> sebaiknya terhubung dengan id input melalui atribut for?
7. Apa perbedaan <textarea> dengan input type text?
8. Apa fungsi semantic HTML seperti <header>, <nav>, <main>, <section>, <article>, <aside>, dan
<footer>?
9. Apa fungsi required, min, max, dan minlength?
10. Apa perbedaan elemen <audio> dan <video>?

jawab:

Fungsi <table>, <tr>, <th>, dan <td>:
<table> → membuat tabel.
<tr> → membuat baris pada tabel.
<th> → membuat sel sebagai judul/header.
<td> → membuat sel untuk data.
Perbedaan <th> dan <td>:
<th> digunakan untuk header/judul kolom, sedangkan <td> digunakan untuk isi/data tabel.
Fungsi colspan:
Untuk menggabungkan beberapa kolom menjadi satu sel.
Fungsi <form>:
Untuk membuat formulir yang digunakan pengguna untuk memasukkan dan mengirim data.
Perbedaan radio button dan checkbox:
Radio button biasanya digunakan untuk memilih satu pilihan, sedangkan checkbox dapat digunakan untuk memilih lebih dari satu pilihan.
Mengapa <label> dihubungkan dengan id melalui for?
Agar label terhubung dengan input sehingga lebih mudah digunakan dan lebih aksesibel. Saat label diklik, input yang terkait juga dapat dipilih.
Perbedaan <textarea> dan <input type="text">:
<input type="text"> digunakan untuk teks satu baris, sedangkan <textarea> digunakan untuk teks yang bisa terdiri dari beberapa baris.
Fungsi semantic HTML:
<header> → bagian kepala halaman.
<nav> → navigasi/menu.
<main> → konten utama.
<section> → bagian/kelompok konten.
<article> → konten mandiri, seperti artikel.
<aside> → konten tambahan/samping.
<footer> → bagian bawah halaman.
Fungsi required, min, max, dan minlength:
required → input wajib diisi.
min → menentukan nilai minimum.
max → menentukan nilai maksimum.
minlength → menentukan jumlah karakter minimum.
Perbedaan <audio> dan <video>:
<audio> digunakan untuk memutar suara/audio, sedangkan <video> digunakan untuk memutar video, biasanya beserta tampilan gambar.
